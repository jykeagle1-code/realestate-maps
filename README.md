# 아파트 입주 지도

지역별 아파트 입주 단지를 카카오맵 위에 표시하는 정적 페이지입니다. (원 넓이 = 세대수, 원 색 = 입주 연도)

- 자료: 한국부동산원 공동주택 단지 식별정보(공공데이터포털, 이용허락 제한 없음), 국토교통부 건축HUB 주택인허가, 한국부동산원 청약홈 분양공고, 한국부동산원 주간 아파트 매매가격지수(R-ONE OpenAPI), 통계청 주민등록인구·행정구역 경계(southkorea-maps)
- 좌표: 카카오 로컬 API로 주소 변환
- 지도: 카카오맵 JavaScript SDK (이 도메인에서만 작동하도록 제한된 키)
- 참고용 자료입니다.
